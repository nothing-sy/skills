````markdown

```
````

- 块内全部为自然语言指令，不承载元数据字段。
- 处理成功后，整个 ` ```agent ... ``` ` 块从文件中删除。

## 多行指令

块内可直接换行书写，无需续行缩进：

````markdown
```agent
为下方 DailyPriceTrend 组件撰写说明，需包含：
- 组件职责（一句话）
- 依赖的数据字段
- 与 OverviewCard 的协作关系
````

## 识别规则

| 类型 | 规则 |
|------|------|
| 待处理 | 开围栏 `^[ \t]*```agent[ \t]*$`，闭围栏 `^[ \t]*```[ \t]*$` |
| 已跳过 | 开围栏 `^[ \t]*```agent-skip[ \t]*$` |
| 错误记录 | `<!--[ \t]*@agent-error:([^>]+)-->`，位于代码块紧下方 |

> 成功完成的指令块会从文件中移除，不以其他形式保留。

## section-below 边界判定

1. **起点：** ` ```agent ` 块闭合围栏的下一行。
2. **终点**（先遇到即停）：
   - 下一条 ` ```agent ` / ` ```agent-skip ` 块
   - 同级或更高级 Markdown 标题（`#` 数量 ≤ 锚点标题级别）
   - 文件末尾
3. **锚点标题：** 向上最近的一个 Markdown 标题；若上方无标题，则任意 `#` 标题均视为边界。
4. **写回：** 更新区间内内容后，删除 ` ```agent ` 代码块，仅保留产出正文。

## 完成与失败形态

**成功 — 处理前：**

````markdown
```agent
根据 src/api/modules/foo/index.ts 更新下方接口清单表格。
```

| 接口 | 方法 | 路径 | 说明 |
|------|------|------|------|
````

**成功 — 处理后：**

```markdown
| 接口 | 方法 | 路径 | 说明 |
|------|------|------|------|
| getOverview | GET | /foo/overview | 获取概览 |
```

**失败 — 保留代码块并附错误注释：**

````markdown
```agent
根据 src/api/modules/notExist/index.ts 补全下方接口表。
```
<!-- @agent-error: 找不到 src/api/modules/notExist/index.ts -->

## 接口清单

| 接口 | 方法 | 说明 |
|------|------|------|
````

## 手动跳过

将围栏标识符改为 `agent-skip`，扫描时永久忽略：

````markdown
```agent-skip
暂不生成性能优化章节。
```
````

`@agent-error` 仅作为 HTML 注释存在，用于失败重试提示。
